# 城市匹配测试

一个可独立运行的纯静态城市人格匹配测试备份，包含 45 道题、11 个生活维度和 28 座候选城市。

## 特点

- 无需服务器、数据库、账号或兑换码
- 计分、结果与历史记录均在浏览器本地完成
- 适配手机与桌面浏览器
- 可直接通过 GitHub Pages 发布

## 本地预览

由于页面使用 ES Module，请在项目目录运行静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 说明

本项目是用于防止公开测试页面失效的独立静态备份。它不包含原站的账号、兑换码、订单、支付、统计或其他后端服务。测试结果仅供娱乐和自我探索参考。
